# 쿠팡파트너스 x 텔레그램 자동화 — PRD

> 어떤 AI가 읽어도 그대로 구현할 수 있는 요구사항 문서.
> 마지막 수정: 2026-11-04 / 상태: 기획 확정, 미구현

## 1. 목적

봇 1개로 채널 2개를 운영한다. 사람의 손을 타는 건 검수(승인)뿐이다.

- **송출 채널(공개)**: 하루 3~6개 딜 자동 발행
- **대시보드 채널(나 전용)**: 매일 결산 + 취소/에러/송출로그 자동 수신
- **목표 상태**: 손 안 대고 1주일 연속 돌아가기

## 2. 범위 (Scope)

### In-scope
- 골드박스 / 키워드검색 / 카테고리베스트 수집 → 필터 → 송출 채널 발행
- 쿠팡 URL → 파트너스 딥링크 변환 후 발행
- 일일결산 / 주간결산 / 취소감지 / 에러알림을 대시보드로 푸시
- 중복발행 방지, 가격 히스토리 기록, 파트너스 고지문구 자동 삽입
- SQLite 로컬 저장, APScheduler 스케줄 실행, 24시간 상시 실행(`python bot.py`)

### Out-of-scope (v1에서 안 함)
- 가격 실시간 알림의 외부 크롤링 (API에 가격 히스토리 없음, 자체 DB 비교로만 대체)
- 실시간 주문 웹훅 (파트너스 리포트는 일 1회 배치, 매일 15시 갱신)
- 결제/유료구독/다계정/웹 대시보드
- 클라우드 배포 (v1은 로컬 PC 상시 실행, Phase 4 이후 별도 결정)

## 3. 전제조건

- 쿠팡 파트너스 **최종승인 완료 계정** (누적 매출 15만원 이상). 승인 전이면 API 키가 있어도 호출 불가.
- `.env` 4개 값 필수: `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_PUBLIC_CHANNEL_ID`, `TELEGRAM_ADMIN_CHAT_ID` (실제로는 5개, 토큰+채널2개+키2개)
- 텔레그램 봇은 @BotFather 발급, 송출 채널에 **관리자**로 등록되어 있어야 발행 가능
- 기존 자산 (재사용 필수, 새로 만들지 말 것):
  - `coupang_api.py` — HMAC 인증 + goldbox/deeplink/search/bestcategories/orders 구현済
  - `test_api.py` — 골드박스 호출 테스트
  - `requirements.txt` — requests, python-dotenv, python-telegram-bot>=21.0, apscheduler
  - `.env.example` — 환경변수 템플릿

## 4. 사용자 / 채널 정의

| 구분 | 대상 | 설명 |
|---|---|---|
| 송출 채널 | 불특정 구독자 | 공개 채널, 봇이 관리자 권한으로 카드 발행. 고지문구 필수 |
| 대시보드 | 운영자 본인 1명 | 비공개 채널 또는 본인 DM. 결산/로그/에러 수신 + 명령어 입력 |
| subId | 추적용 | `send`=자동발행, `manual`=수동발행, `test`=테스트. 리포트에서 구분 |

## 6. 기능 요구사항 요약

- F1 수집: 골드박스/키워드/베스트카테고리 조회, 시간당 호출 제한 준수, 결과 1시간 캐시
- F2 필터: D4 조건 + 품절/판매중지(딥링크 실패) 시 스킵
- F3 변환: 쿠팡 URL → 딥링크(`shortenUrl`) 변환, subId 부여, 실패 시 원본 URL로 발행 금지
- F4 발행: 송출 채널에 이미지+이름+가격+버튼 카드 발행, posts 테이블 기록
- F5 수동: `/검색 <키워드>` 후보 5개 → 번호 선택 → 미리보기 → 발행/취소. URL 붙여넣기 동일 플로우
- F6 리포트: 16시 일일결산(클릭/주문/수익/취소/GMV/전일대비/TOP5), 월요일 주간결산, 취소 별도 경고
- F7 관측: 송출로그 + API 401/429/네트워크 에러 즉시 대시보드 알림
- F8 제어: `/상태` (오늘 발행수/API상태/스케줄), `/발행취소` (마지막 예약 취소)

## 7. 성공 기준 (Acceptance)
